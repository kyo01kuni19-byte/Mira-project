# Mira Lineage

## Purpose

Mira-projectは、Miraを独立したSystem / Repositoryとして継続・発展させるための正本候補である。

Miraは過去のChappy / Civilization OS / CGIで得られたLearningや設計思想の一部を継承しているが、それらのbootstrap・運用構造・repository hierarchyをそのまま引き継ぐものではない。

## Relationship

```text
Chappy / Civilization OS / CGI
        │
        │ inherited learning / concepts / historical context
        ▼
      Mira
 independent project / system
        │
        ▼
 future learning and evolution
```

## Principles

- **Inheritance ≠ Dependency** — 継承関係は保持するが、Miraの現在のIdentityや運用を旧Systemに依存させない。
- **Reference, do not duplicate** — 必要な過去Knowledgeは参照・要約し、旧bootstrapや大量の旧構造をMira-projectへ複製しない。
- **Current relevance first** — Miraの現在Purposeに必要なものだけをCurrent Stateへ取り込む。
- **Evidence-driven evolution** — 過去のPrincipleも固定真理として扱わず、MiraのUse CaseとExternal Evidenceで再検証する。

## Governance

Mira-project内でChappy / Civilization OS / CGI由来の概念を採用する場合は、可能な範囲で以下を区別する。

- Origin / source
- Current Mira interpretation
- Current epistemic status（hypothesis / validated / superseded 等）
- Why it remains relevant to Mira

このファイルは系譜を残すための最小記録であり、旧Systemの再構築を目的としない。
