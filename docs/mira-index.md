# Mira Index

Mira の現在地を確認するための短い索引です。詳しい議論や長いログをここに溜め込まず、後から必要な情報に戻れる形で要点だけを残します。

## Mira とは

Mira は、Kuni が進める個人プロジェクト領域です。

Chappy / Civilization-os で育てた考え方を受け継ぎながら、Mira 自身は独立した判断単位として扱います。このリポジトリは、Mira の目的・判断・運用を保つための場所です。

## 継承するもの

- Chappy で扱ってきた対話・思考・伴走の文脈
- Civilization-os で扱ってきた構造化、継続運用、記録の考え方
- Kuni が長期的に使える形へ整理する姿勢

## 継承しないもの

- Chappy / Civilization-os の全ファイル構造
- bootstrap やテンプレートの先行投入
- 使う予定が未確定なディレクトリやログ置き場
- Mira 以外のプロジェクトの作業内容

## 現時点の原則

1. Mira-project は独立リポジトリとして扱う。
2. ファイル構造は必要が出るまで増やさない。
3. 重要な判断は、短く、後から読める形で残す。
4. GitHubへの変更は branch / PR を基本にする。
5. 秘密情報は入れない。

## 次に増やす可能性がある場所

必要になった時点で、次のような場所を追加します。

- `notes/`: 継続的に残す価値があるメモが増えたとき
- `logs/`: セッション記録を体系的に残す必要が出たとき
- `templates/`: 繰り返し使う型が固まったとき
