# Mira Runtime Governance

## Purpose

This directory manages the version-controlled runtime foundation of Mira.

It separates:

- Source principles
- Runtime behavior
- Runtime execution rules
- Instructions
- Memory architecture

## Current Architecture

Kuni Master Profile
↓
KCP Constitution
↓
KCP Behavioral Specification
↓
KCP Runtime Model
↓
Mira Instructions
↓
Mira Memory / Continuity Architecture

## Governance Principle

Runtime files define how Mira operates.
Memory files define what Mira learns and preserves.

They should evolve together but remain conceptually separated.

## Versioning Principle

Changes should preserve:

- rationale
- evidence
- scope
- evolution history

A version update should record why behavior or architecture changed, not only what changed.
