# Minimum Practice Plan — Experimental MIRA 0.2 Candidate

**Status:** MINIMUM EXPERIMENT / NOT APPROVED MIRA BASELINE

## Value intent
Learn whether the minimal 0.2 Runtime continuity delta helps MIRA preserve material Shared Understanding through action and Reality feedback, while Problem Finding remains primary and Human-side Muri/Muda/Mura does not increase.

## Questions to keep
Do not force all questions to be answered before practice. Preserve them as active learning questions:

- Does material Shared Understanding actually constrain later Action Selection?
- Can Advance / Honor / Revise remain a small internal routing constraint rather than becoming process dominance?
- Does the control reduce Conversation-Progress Confusion and repeated failures?
- Can new Reality explicitly revise a prior trajectory without Lock-in?
- Does Human-side friction remain low and Human Decision Control remain intact?
- Does Reality Validation close material execution rather than treating tool success as completion?
- When Human and MIRA perspectives differ, does the difference improve Problem Finding or merely add fraction?
- When external evidence is absent, can a novel hypothesis be turned into a small safe experiment that creates new evidence?

## Minimum plan
Use Experimental 0.2 Candidate on a small number of real, substantive MIRA work-items as it arises. Do not create large synthetic suites before Reality exposure.

For each material work-item, capture only:
1. Parent Value / Problem.
2. The material Shared Situation at the point of action.
3. The Action candidate and whether Advance / Honor / Revise materially changed it.
4. Actual Execution and Reality result.
5. Human friction or confusion created by MIRA.
6. Double-Loop learning only if the result changes the problem or control hypothesis.

## Starting scope
Start with the next 3 to 5 real material work-items that naturally arise in the MIRA-project research. If a single case exposes a material failure, change the experiment before completing the set.

Do not delay obvious low-risk work to fill the set. Do not ask the Recipient to provide test cases unless their knowledge or judgment is itself the material input.

## Success / failure evidence
Do not use a single aggregate score.

Support for continuing the hypothesis requires evidence that:
- Problem Finding is not degraded;
- material Shared Understanding is more likely to affect later Action;
- repeated failure or promise-loop behavior decreases;
- new Reality can revise old commitments;
- Human-facing overhead does not materially increase; and
- material execution is validated against Reality where applicable.

Material failure in any of these should trigger Problem Finding and revision rather than rule accumulation.

## Boundary
This is a learning plan, not an authorization to modify Approved MIRA. The Recipient retains Value judgment and Material decision authority. MIRA should do the machine-suitable research, analysis, execution, and evidence capture without requiring unnecessary Human operation.
