# Master Profile Extraction Pilot v0.1

## Purpose

Validate whether Kuni Master Profile can be decomposed into Unified Learning Database entities without losing meaning, origin, or relationships.

The goal is not to rewrite the Master Profile.

The goal is to preserve the original source while creating structured Knowledge Entities.

---

# Extraction Principle

Kuni Master Profile is treated as a Source Container.

It may contain multiple entity content types:

- Value
- Principle
- Capability
- Practice
- Architecture
- Learning
- Project Knowledge

Each extracted entity keeps:

Hierarchy
Object
Purpose
State
Relationship
Formation / Evolution Trace
Evidence
