# Master Profile Core Architecture Extraction v0.1

## Purpose

Extract Kuni Way Master Profile into Unified Learning Database entities without summarization loss.

The goal is reconstruction, not compression.

Source:
Kuni Way Master Profile v3.2 Full Review Draft 10

## Extraction Principle

The Master Profile is treated as a Source Container.

It contains multiple Knowledge Entity types:

- Value
- Principle
- Capability Logic
- Practice
- Architecture Rule
- Learning Pattern
- Governance Pattern

Each extracted entity keeps:

- Origin
- Context
- Evidence
- Formation history
