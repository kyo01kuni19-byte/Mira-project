# Unified Learning Database — Master Profile Learning System Extraction v0.1

## Purpose

Extract Learning System related concepts from Kuni Way Master Profile into reusable Knowledge Entities.

The goal is not summarization. The goal is reconstruction.

Each entity follows the Unified Knowledge Entity Model:

- Hierarchy
- Object
- Purpose
- State
- Relationship
- Formation / Evolution Trace
- Evidence
