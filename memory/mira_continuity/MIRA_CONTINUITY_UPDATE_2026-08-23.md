# 2. Major Learning

Memory Design is Reconstruction Design.

- Identity
- Capability
- Understanding
- Value creation capability

# 7. Hierarchy Learning

Hierarchy is not Memory-specific.

Hierarchy represents where an Entity exists in terms of scope/value/application.

Candidate:

- Value / Principle level
- Mira Capability level
- Reusable Knowledge level
- Project level
- Evidence / Case level

Hierarchy and Content Type must not be mixed.

---

# 8. Relationship Learning

Relationship represents current structure between Entities.

Avoid excessive Relationship categories.

Candidate core relationships:

- Contains / Composition
- Depends on
- Associated with
- Supported by Evidence

Evolution history should not be mixed into current Relationship.

---

# 9. Formation / Evolution Trace

Purpose:

Explain how an Entity came into existence and changed.

Important information:

- Origin (Where)
- Creator / Source Actor (Who)
- Trigger (Why / What caused emergence)
- Transformation (What changed)
- Evolution history
- Critical Evidence

Do not store all history. Store enough to reconstruct meaning.
